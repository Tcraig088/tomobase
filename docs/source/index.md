# Description

This is the landing page documentation for TomoBase. The TomoBase (tomobase) library is a library of tools for **S**canning **T**ransmission **E**lectron **T**omography **(STEM)**. It can be used as a standalone library for STEM. But is primarily designed as an extensible plugin system to allow tomography users to build more advanced tools for time series reconstructions or multidimensional applications.

For source code visit [Github](https://github.com/Tcraig088/tomobase).
